# Mission Control Component Package

This package contains the MainContent component for the "Mission Control" home view, along with its sub-components (tables and hover cards).

## How to Use

1.  Copy this `MissionControl` folder into your React project (e.g., into your `src/components/` directory).
2.  Ensure you have the necessary dependencies installed in your project:
    ```bash
    npm install recharts
    ```
3.  Import and use the `MainContent` component in your app.

## Dependencies
This component relies on several sub-components included in this folder.
It requires **`recharts`** for data visualization.

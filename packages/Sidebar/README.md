# Sidebar Component Package

This package contains the Sidebar component for the left navigation rail.

## How to Use

1.  Copy this `Sidebar` folder into your React project (e.g., into your `src/components/` directory).
2.  Import and use the `Sidebar` component in your app.

## Dependencies
This component relies on `useRipple.ts` and `Icons.tsx` which are included in this folder.
It also assumes you have `google-symbols` and `material-symbols-outlined` fonts available in your project (e.g. via Google Fonts).
